# PORTFOLIO CÁ NHÂN – NGUYỄN BÁ TRƯỜNG

## 1. Giới thiệu dự án

Đây là website Portfolio cá nhân của **Nguyễn Bá Trường**, sinh viên ngành Công nghệ thông tin tại Trường Đại học Đại Nam.

Website được xây dựng nhằm giới thiệu bản thân, quá trình học tập, kỹ năng lập trình, các dự án và thông tin liên hệ.

Dự án được chỉnh sửa, Việt hóa và phát triển từ một mẫu Portfolio có sẵn, đồng thời sử dụng Git và GitHub để quản lý phiên bản và ghi lại quá trình thực hiện.

## 3. Công nghệ sử dụng

- HTML5 – Xây dựng cấu trúc website.
- CSS3 – Thiết kế và trình bày giao diện.
- JavaScript – Xử lý các chức năng tương tác.
- jQuery – Hỗ trợ thao tác và hiệu ứng.
- Git – Quản lý lịch sử thay đổi mã nguồn.
- GitHub – Lưu trữ và quản lý dự án.
- GitHub Pages – Triển khai website trực tuyến.

Các thư viện và hiệu ứng được sử dụng trong bài mẫu bao gồm Font Awesome, Typed.js, Particles.js, Vanilla Tilt và ScrollReveal.

## 4. Chức năng website

Website Portfolio gồm các phần chính:

1. **Trang chủ:** Giới thiệu Nguyễn Bá Trường.
2. **Giới thiệu bản thân:** Thông tin cá nhân và định hướng học tập.
3. **Kỹ năng:** Giới thiệu những công nghệ lập trình.
4. **Học vấn:** Thông tin quá trình học tập.
5. **Dự án:** Giới thiệu các sản phẩm và bài thực hành.
6. **Kinh nghiệm:** Quá trình học tập và phát triển kỹ năng.
7. **Liên hệ:** Hiển thị thông tin liên hệ và biểu mẫu.

## 6. Hướng dẫn chạy website trên máy

**Bước 1:** Tải hoặc sao chép repository:

```bash
git clone https://github.com/Truongco0777/K20-Portfolio-Ca-Nhan.git
```

**Bước 2:** Mở thư mục dự án bằng Visual Studio Code.

**Bước 3:** Mở file `index.html` bằng tiện ích Live Server.

**Bước 4:** Kiểm tra giao diện, hình ảnh, liên kết và các hiệu ứng của website.
